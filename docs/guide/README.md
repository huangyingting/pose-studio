# Pose Studio user guide

Pose Studio is a posable 3D mannequin for drawing reference, and a small studio for blocking scenes: pose people, put them in a set, make them act, film them in shots, and export pictures, storyboards and video.

This guide goes through the app part by part. Each page has screenshots with numbered marks; the text after each picture explains the marks.

## The workflow in one minute

1. **A scene**: start from the blank one, or **Main menu → New scene…** for a template.
2. **Cast and set**: add figures and props in the **Scene** outline (left), pick a set in the Library.
3. **Pose and act**: drag the figure's parts to pose it; give it a walk or a motion; each figure's actions are blocks on the timeline.
4. **Shoot**: let the **Director** film the scene, or cut shots and place cameras yourself.
5. **Output**: the storyboard (`B`) and **Export** (`Ctrl E`).

The screenshots are taken from the running app by `npm run doc-shots` (with `npm run dev` going), so they can be made again when the interface changes.
